# HypeTek Mission Control

HypeTek Mission Control is a self-hosted game archive, metadata manager and secure Windows launcher designed for TrueNAS deployments.

The app mounts the primary game archive read-only, keeps Mission Control configuration in persistent storage and can optionally run a private LibreTranslate service for game-description translation.

Upstream project and documentation: https://github.com/HypeTek/hypetek-gamevault
